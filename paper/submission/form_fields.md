## Before you click submit

- [ ] Co-authors have seen the final PDF and agreed in writing -- the portal
      makes you attest to this
- [ ] An ORCID and email for each author
- [ ] You accept the IEEE Access APC (~US$2,000) if accepted; check for a
      waiver if it matters
- [ ] arXiv preprint posted first if you want the timestamp (IEEE permits
      preprints; declare it in the portal's prior-publication question)
- [ ] Final version rebuilt from the IEEE Access template once accepted --
      `main_ieee.tex` is IEEEtran, which is fine for review
